API REFERENCE

Editarr API

The Editarr web app runs on this local HTTP API. Automate scans, reviews, exports, and administration with a personal API key.

OpenAPI 3.1

Base URL

Requests go to your own Editarr server, by default http://localhost:3348. If Editarr runs under a Base URL prefix behind a reverse proxy, put that prefix before every path.

EDITARR_URL=http://localhost:3348
# with a prefix: EDITARR_URL=https://media.example/editarr
curl "$EDITARR_URL/api/system/version" -H "X-Api-Key: $EDITARR_API_KEY"

Authentication

  • API key. Create one in My Profile → API Key and send it in the X-Api-Key header. A key carries your account's own current permissions, never more.
  • Browser session. The web app uses a session cookie. Mutations must be same-origin and include the X-CSRF-Token header.
  • Interactive only. Some account-security operations need a signed-in browser session and return 403 interactive_session_required for API keys.
  • Public. Setup, sign-in, and status endpoints work without credentials and are marked Public.

Errors

Errors return JSON. Access errors include a machine-readable code and a detail message.

StatusMeaning
401No session, or an invalid or revoked API key.
403Missing permission, disabled account, or the operation needs an interactive session or re-authentication.
409Conflict with the current state, such as a stale permission revision.
422Validation failed; detail lists each invalid field.
423Editarr is not set up yet; finish administrator setup first.

Download OpenAPI JSON

Use the machine-readable description with code generators and API clients. A signed-in server also serves its own copy at /openapi.json.
