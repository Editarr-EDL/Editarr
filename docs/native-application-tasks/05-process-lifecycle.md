# NATIVE-05 — Implement cross-platform worker ownership

Status: **DONE**

Dependencies: NATIVE-04. Primary scope: process identity, start/stop/termination,
reconciliation, full-Quit semantics, and macOS/Windows lifecycle tests.

## Background

Current scan-worker detection shells out to `ps`, checks command text, creates a POSIX
session, and terminates an `os.killpg` process group. Windows has none of those contracts.
PID reuse also makes a bare persisted PID unsafe. Workers must survive an HTTP generation
restart but belong to the per-user application for full Quit and crash reconciliation.

## Instructions

1. Introduce one cross-platform process-control interface used by worker launch,
   liveness/identity checks, graceful stop, forced stop, and reconciliation. Avoid a
   broad dependency if standard OS APIs suffice; justify and lock any new dependency.
2. Persist or derive a stable worker identity stronger than PID alone using the existing
   token plus process creation identity/owned IPC where possible. Do not kill a process
   when identity cannot be proven.
3. Implement POSIX and Windows behavior. On Windows, explicitly define Job Object or
   equivalent ownership so HTTP-child restart does not terminate the scan worker.
4. Preserve serial queue reservation, heartbeat, orphan recovery, cancellation, setup
   gate, and controller restart behavior.
5. Implement full application Quit: stop scheduling, request cooperative worker stop,
   wait a bounded interval, terminate only proven owned processes, and leave interrupted
   scan state recoverable/resumable. Do not silently mark it completed or delete history.
6. Handle crashes between reservation, process start, process registration, and heartbeat.
7. Add deterministic unit/integration tests plus actual subprocess tests on macOS and
   Windows. Use isolated databases, tokens, and process trees.

## Fixed decisions

- HTTP restart preserves active scan workers.
- Full Quit stops all Editarr-owned processes and retains recoverable scan state.
- Never terminate by PID without verifying ownership.
- Do not add a service account or machine daemon.

## Acceptance criteria

- [x] No production worker lifecycle relies on `ps`, command substring matching,
  `start_new_session`, or `os.killpg` without a platform adapter.
- [x] PID reuse/identity mismatch tests prove unrelated processes are not signaled.
- [x] HTTP restart preserves a real active worker.
- [x] Full Quit and crash reconciliation leave deterministic resumable state.
- [x] Required macOS and Windows subprocess tests pass on their native hosts.

## Definition of done

Focused queue/worker/restart/process tests and Ruff pass on macOS and Windows,
`git diff --check` passes, and host evidence is recorded. If no Windows host is available,
mark `BLOCKED`, not `DONE`, after completing safe portable work.
